# Заливка силикона на оловянном катализаторе

## Материалы:
+ Вазелин (или другая разделительная смзка)
+ Силикон для форм требуемой твердости
+  Катализатор
+ Краситель для силикона
+ Силиконовое масло для разжижения смеси
+ Бумажные салфетки
+ Бумага для укрывания рабочей поверхности

## Приборы и инструменты:
+ Весы
+ Шприц на 1мл
+ Форма для заливки силикона
+ Пластиковая емкость для смешивания компонентов
+ Деревянная палочка для перемешивания
+ Пластиковая карточка или линейка

## Последовательность действий:
1. Укрыть рабочее место листами бумаги
2. Очистить формы для заливки от остатков силикона
3. Смазать формы тонким слоем вазелина
4. Собрать формы
5. Подготовить пластиковую емкость для силикона (очистить и взвесить)
6. Поставить емкость на весы и обнулить массу
7. Налить требуемое количество силикона
8. Добавить краситель и силиконовое масло - не обязательно
9. С помощью миниатюрного шприца набрать катализатор из расчета 1.5% от массы силикона
10. Аккуратно добавить катализатор в емкость с силиконом (без брызг!)
11. Тщательно перемешать компоненты до однородного цвета
12. Медленно залить силикон в форму
13. Подождать пока выйдут воздушные пузыри (5-10 минут)
14. Удалить излишки силикона с помощью пластиковой карточки
15. Накрыть формы крышками, если требуется
16. Поставить формы с силиконом, а также емкость с остатками силикона на горизонтальную поверхность
17. Не ранее чем через 12 часов проверяем остатки силикона в форме, если силикон застыл, то разбираем формы и извлекаем отливку.
