# Заливка силикона на платиновом катализаторе

## Материалы:
+ Вазелин (или другая разделительная смзка)
+ Силикон для форм требуемой твердости: компоненты A и B
+ Краситель для силикона
+ Силиконовое масло для разжижения смеси
+ Бумажные салфетки
+ Бумага для укрывания рабочей поверхности

## Приборы и инструменты:
+ Весы
+ Форма для заливки силикона
+ Пластиковая емкость для смешивания компонентов
+ Деревянная палочка для перемешивания
+ Пластиковая карточка или линейка

## Последовательность действий:
1. Укрыть рабочее место листами бумаги
2. Очистить формы для заливки от остатков силикона
3. Смазать формы тонким слоем вазелина
4. Собрать формы
5. Подготовить пластиковую емкость для силикона (очистить и взвесить)
6. Поставить емкость на весы и обнулить массу
7. Налить требуемое количество компонента А
8. Обнулить весы
9. Налить такое же количество компонента В, как и в пункте 7
10. Добавить краситель и силиконовое масло - не обязательно
12. Тщательно перемешать компоненты до однородного цвета
13. Медленно залить силикон в форму
14. Подождать пока выйдут воздушные пузыри (5-10 минут)
15. Удалить излишки силикона с помощью пластиковой карточки
16. Накрыть формы крышками, если требуется
17. Поставить формы с силиконом, а также емкость с остатками силикона на горизонтальную поверхность
18. Не ранее чем через 4 часа проверяем остатки силикона в форме, если силикон застыл, то разбираем формы и извлекаем отливку.
