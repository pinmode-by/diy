# Рецепт смеси для травления печатных плат

## На 100 см<sup>2</sup> стеклотекстолита требуется:

+ 30г лимонной кислоты
+ 7г поваренной соли
+ 100мл 3% раствора перекиси водорода


## Справка. Содержание меди в 100 см<sup>2</sup> стеклотекстолита:

| Толщина меди, мкм | Масса меди, г| 
|----               |----        |
| 18                 | 1.6       |
| 35                 | 3.2       |
| 70                 | 6.4       |
