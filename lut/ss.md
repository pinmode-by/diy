# Изготовление односторонних печатных плат методом ЛУТ

## Материалы:
+ Односторонний стеклотекстолит требуемой толщины и размера
+ Термотрансферная бумага
+ Перекись водорода, водный раствор 3%
+ Лимонная кислота
+ Соль поваренная ЭКСТРА (без йода!)
+ Лист чистой бумаги формата А4
+ Ровный деревянный брусок
+ Ацетон 
+ Бумажные салфетки

## Приборы и инструменты:
+ Ножницы по металлу
+ Мелкая наждачная бумага (зерно ...)
+ Ножницы для бумаги
+ Утюг
+ Лазерный принтер
+ Пластиковая ванночка для смешивания реагентов и травления 
+ Деревянная палочка для перемешивания раствора
+ Сверлильный станок или дрель
+ Сверла
